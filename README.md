## Background

BeanLab is building an automated quality-inspection pipeline for canned bean trays.
A tray photograph enters the pipeline; individual beans are segmented; a CNN scores
each bean as Good or Bad; a tray-level feature vector is derived from those scores;
and an XGBoost model predicts the human appearance rating on a **1–5 ordinal scale**.

Ground-truth labels are expert ratings collected across three growing seasons
(2023, 2024, 2025) with different field teams and camera setups.

```
Tray photo  →  Instance segmentation  →  Per-bean CNN scoring  →  Tray features  →  Rating (1–5)
   (JPG)         (Watershed / SAM)        (ConvNeXt-Tiny)          (XGBoost)
                       ↓                        ↓                       ↓
                 ~200–300 bean            prob_bad ∈ [0,1]       mean_prob_bad
                   crops per tray          per bean crop           n_beans  …
```

The codebase was written over several months by two ML engineers rotating in and out.
It runs without crashing. The reported 5-fold CV QWK is 0.62. Your job is to determine
whether that result can be trusted.

## What is in this repo

```
pipeline/
    dataset.py      — crop loading, dataset splitting, augmentation
    segment.py      — instance segmentation via distance-transform watershed
    train.py        — CNN training loop (ConvNeXt-Tiny)
    features.py     — tray-level feature engineering from per-bean CNN scores
    evaluate.py     — XGBoost cross-validation and threshold application

data/                        ← generated by make_sample_data.py (run this first)
    ratings.csv              — 60 synthetic trays: tray_id, year, human_rating (1–5)
    sample_beans/            — 60 CSVs, one per tray: bean_id, prob_bad
                               each file has 160–320 rows (one row per bean)

QUESTIONS.md        — the five questions you need to answer
SOLUTION.md         — fill this in and submit
make_sample_data.py — generates the synthetic data above
requirements.txt
```

### What the synthetic data contains

| File | Columns | Purpose |
|------|---------|---------|
| `data/ratings.csv` | `tray_id, year, human_rating` | Tray-level labels (60 trays × 3 years) |
| `data/sample_beans/<tray_id>_results.csv` | `bean_id, prob_bad` | Per-bean CNN scores for each tray |

Ratings span 1–5 with a realistic distribution (skewed toward 3–4).
`prob_bad` values are synthetic but follow the same bimodal structure as real
CNN output: most beans near 0.0 (good), a fraction near 1.0 (defective).

> **Real images are not provided and not needed.**
> `dataset.py` and `train.py` require real tray photos and a GPU — the bugs
> in those files are found by reading, not by running.
> `features.py` and `evaluate.py` run fully on the synthetic data above.
