## Background

BeanLab is building an automated quality-inspection pipeline for canned bean trays.
A tray photograph enters the pipeline; individual beans are segmented; a CNN scores
each bean as Good or Bad; a tray-level feature vector is derived from those scores;
and an XGBoost model predicts the human appearance rating on a **1–5 ordinal scale**.

Ground-truth labels are expert ratings collected across three growing seasons
(2023, 2024, 2025) with different field teams and camera setups.

The codebase was written over several months by two ML engineers rotating in and out.
It runs without crashing. The reported 5-fold CV QWK is 0.62. Your job is to determine
whether that result can be trusted.

---

## What is in this repo

```
pipeline/
    dataset.py      — crop loading, dataset splitting, augmentation
    segment.py      — instance segmentation via distance-transform watershed
    train.py        — CNN training loop (ConvNeXt-Tiny)
    features.py     — tray-level feature engineering from per-bean CNN scores
    evaluate.py     — XGBoost cross-validation and threshold application

data/
    ratings.csv            — synthetic tray ratings (tray_id, year, human_rating)
    sample_beans/          — synthetic per-tray CSVs (bean_id, prob_bad)
    (generated by make_sample_data.py — run this first)

QUESTIONS.md        — the five questions you need to answer
SOLUTION.md         — fill this in and submit
make_sample_data.py — generates the synthetic data in data/
requirements.txt
```
